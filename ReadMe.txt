How to run:
First make sue you are on Java 21, to check go under project structure, modules, then switch to 21
Then make sure your set to Bundled(Maven 3) under setting > build, execution, deployment > build tools > maven
After that make sure your pom file has all the sources downloaded and synced
Then the LostfoundApplication, wait a few seconds
When you see a line that says 'Tomcat started on port 8080' in the run console your ready for the next step
Go into your browser of choice and type localhost:8080 and press enter and you'll be on the site, enjoy
